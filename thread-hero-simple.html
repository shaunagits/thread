One panel. Whichever tools happen to be yours.

No dashboard content, no callouts, no copy. Tools at the top, threads converging, one wireframe panel underneath. The only text anywhere is placeholder bars.

The hard part is saying any rather than these. Each direction below solves that differently. All three animate on load, CSS only, under two seconds, behind prefers-reduced-motion.

1. Converge

Seven tools drop into one node and open into one panel. The seventh slot is drawn dashed and empty, which is what carries the "and whatever else you run" idea. Static, so it works as an image anywhere: social card, PDF, print.

2. Swap

Same funnel, five slots, and the tools change. One set is email, reporting, invoicing, shipping and payments. The other is scheduling, crews, site, plant and permits. Panel never changes.

This is the one that actually says "any." The other two imply it; this one demonstrates it. The cost is a slow loop rather than a one-time animation, which is more motion than the rest of the site has. Nine second cycle, long holds, no bounce. Reduced motion gets set one, still.

3. Pick any

Twelve tools drawn faintly across the top. Five are picked out and threaded down into the panel. The unpicked ones stay on the page, which is what makes the choice legible: this is your five out of everything, and someone else's five would be different.

Static, and the widest of the three. Adding the swap from direction 2 to the picked set is a two line change if you want it later.

Notes

Phone. All three are 900 by 400, so they scale down to 390 without panning. Below about 600px the tool row wants to become two rows of glyphs; the threads then start from both rows. Same drawing, one media query.

Glyphs. Deliberately generic. No brand marks, no logos, nothing that implies a partnership you do not have, and nothing that dates. Swapping one out for a different trade is a single <use> line.

Questions. Does the panel wireframe want to stay this generic, or should it hint at content? Is the looping swap in direction 2 too much motion for the rest of the site?
